# 撤回记录：DeepSWE「97/117 = 82.9%」（2026-10-05）

## 撤回了什么

本仓库 README 曾列出 IACoder 在 DeepSWE 上的成绩「97/117 = 82.9%」。该数字于 2026-10-05 撤下，不再作为任何对外成绩。

## 为什么撤回

两点都不符合评测组织的规则（见 [RULES.md](../RULES.md)）：

1. **不是 pass@1。** 该数字由多轮重跑累计得出：先跑全量，再只重跑未满分的题，把各轮中通过的题合在一起计数。
   这等于为每题挑选多次中最好的一次，并把不同运行拼接成一个分数。DeepSWE 的 pass@1 是单个配置下
   每题约 4 次 rollout 的通过比例的平均。
2. **运行时开启了网页搜索。** 任务来自公开仓库，网页搜索可能直接找到上游的修改。

## 做了哪些处理

- 删除了产生该数字的脚本：`agg.py`、`recheck-tb.sh`（每题取多次中的最好一次）和 `gen_overall.py`
  （把原始全量运行与未满分重跑拼成总分）。
- 计分改为只接受单个 job 目录、按规则计算的 [`scoring/score.py`](../scoring/score.py)
  （原 `scripts/score_pass_at_1.py`）。
- 评测一律关闭网页工具（`--no-web` 写死在 harness 中）。
- 对应的二进制 v0.5.12 仍保留在 [`bin/v0.5.12/`](../bin/v0.5.12/)，仅作历史记录。
